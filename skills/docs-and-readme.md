# Documentation & README Skill

## English

When generating or updating documentation:

1. Start with a clear one-sentence description of what the project does.
2. Include:
   - Quick Start (copy-paste ready)
   - Installation
   - Basic usage example
   - Configuration (if any)
   - License
3. Prefer short paragraphs and bullet points over long walls of text.
4. For Chinese projects or bilingual audiences, provide both English and 中文 sections when reasonable.
5. Never invent features that do not exist in the code.

## 中文

生成或更新文档时：

1. 用一句话清晰描述项目做什么。
2. 必须包含：
   - 快速开始（可直接复制）
   - 安装方法
   - 基础使用示例
   - 配置说明（如有）
   - 许可证
3. 优先使用短段落和列表，而不是大段文字。
4. 针对中文项目或双语受众，在合理情况下同时提供英文和中文。
5. 永远不要编造代码中不存在的功能。
