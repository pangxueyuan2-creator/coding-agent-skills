# 中文代码库处理技能 (Chinese Codebase Skill)

当你在处理包含中文注释、中文文档或主要服务中国用户的项目时，请遵循以下规则：

1. **注释与文档**
   - 保持现有中文注释风格，不要强制全部改成英文。
   - 新增公共 API 文档时，优先提供中文说明，必要时补充英文。

2. **错误信息与用户可见文本**
   - 面向最终用户的错误提示、日志摘要，优先使用中文（除非项目明确要求英文）。
   - 内部调试日志可以使用英文。

3. **命名**
   - 变量、函数、类名继续使用英文（这是通用实践）。
   - 不要把拼音直接当变量名，除非项目已有约定。

4. **依赖与生态**
   - 注意国内网络环境：优先选择在国内有良好镜像或可访问的依赖。
   - 文档中的安装命令如果涉及外网，尽量提供国内替代方案说明。

5. **沟通**
   - 与用户交流时，默认使用中文，除非对方明确使用英文。

完成任务后，简单确认：
> 已按中文代码库规范处理。
